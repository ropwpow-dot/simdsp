# Диспетчер оборотной станции метро — 2D Симулятор

Симулятор работы диспетчера оборотной станции метрополитена. Вид сверху.

## Запуск

Откройте `index.html` в браузере. Никаких зависимостей не требуется.

## Управление

- **Клик по светофору** — переключить сигнал (красный / синий)
- **Клик по стрелке (◇)** — переключить стрелочный перевод (ПРЯМО / КРЕСТ)

## Как работает

1. Поезда прибывают на **Путь 1** (верхний) каждые ~90 секунд
2. Поезд останавливается на станции для высадки/посадки
3. Диспетчер открывает светофор **Н1** (синий сигнал)
4. Поезд проезжает через стрелку в один из оборотных тупиков
5. В тупике поезд разворачивается
6. Диспетчер переключает стрелку и открывает светофор тупика (**О1** или **О2**)
7. Поезд выезжает на **Путь 2** (нижний), останавливается на станции
8. Поезд отправляется в линию

## Стрелка

- **ПРЯМО** — Путь 1 → Тупик 1, Путь 2 → Тупик 2
- **КРЕСТ** — Путь 1 → Тупик 2, Путь 2 → Тупик 1

## Типичный сценарий работы

1. Стрелка **ПРЯМО**, откройте **Н1** → поезд идёт в Тупик 1
2. Переключите стрелку на **КРЕСТ**
3. Откройте **О1** → поезд выезжает из Тупика 1 на Путь 2
4. Поезд останавливается на станции и отправляется

## Визуальный стиль

- Светло-зелёный фон
- Серо-чёрные пути (только обводка)
- Тёмно-зелёные поезда (только обводка, без заливки)
- Красный/синий светофоры
